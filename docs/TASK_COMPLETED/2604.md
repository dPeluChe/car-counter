**11. State dataclasses** (`carcounter/state.py`)

**12. Event-driven architecture** (`carcounter/engine.py`)
- `ProcessingEngine` con `EngineState` enum (IDLE/RUNNING/PAUSED/STOPPED/ERROR)

- Base para futuras UIs (web, desktop)
