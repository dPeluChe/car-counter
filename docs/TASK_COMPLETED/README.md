# Tareas completadas

## Estructura
- Un archivo por mes: `YYMM.md` (por ejemplo `2609.md` = septiembre 2026).
- `2512.md`, `2603.md` y `2604.md` conservan el formato heredado `DONE-NNN`.

## Reglas
1. **Un archivo por mes**: todo lo completado ese mes va en el mismo archivo.
2. **Fechar cada sección**: `## YYYY-MM-DD: Descripción`.
3. **Usar la clave** de TASK_TODO.md (`TODO-NNN`).
4. **Detallar lo hecho** como `- [x]`, con rutas de archivo y funciones.
5. **Contexto breve** en `Notes:` con commits o PR.
6. **Sin bloques de código.**
7. **Mover, no copiar**: al archivar, quitar de TASK_TODO.md.
8. **Conservar `added:`** cuando la tarea lo tenga.
